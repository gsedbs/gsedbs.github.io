# 作品集网站 · 使用说明

一个纯静态的单页作品集网站，**双击 `index.html` 就能在浏览器里打开**，不需要装任何软件、不需要联网。

## 一、改文字

所有文字都在同一个文件里：

```
assets/data/content.js
```

用记事本或 VS Code 打开，改引号里的内容即可，保存后刷新浏览器。

| 要改的东西 | 找哪一行 |
|---|---|
| 姓名 | `name: "林岚"` |
| 一句话头衔 | `title: "视觉设计师 / 品牌与平面"` |
| 口号 | `tagline` |
| 自我介绍 | `intro` |
| 邮箱 / 电话 / 微信 / 城市 | `contact: { ... }` |
| 作品列表 | `works: [ ... ]` |
| 奖项 | `awards: [ ... ]` |
| 工作经历 | `experience: [ ... ]` |

> 注意事项：字符串请用英文引号 `"`；每一条之间用英文逗号 `,` 隔开；最后一条后面不要加逗号。

## 二、换图片

| 放什么 | 放哪里 | 建议尺寸 |
|---|---|---|
| 证件照 / 形象照 | `assets/img/portrait.jpg` | 3:4 竖图，800×1067 以上 |
| 作品图 | `assets/img/works/` 里，命名随意 | 4:3 横图，1200×900 以上 |
| 奖状扫描 | `assets/img/awards/` | 3:4 竖图 |

换作品图有两种方式：

1. **直接用同名文件覆盖**——比如把新图命名为 `w1.jpg` 覆盖掉原来的，页面会立刻更新；
2. **或者改路径**——把新图丢进 `works` 文件夹，然后在 `content.js` 里把 `image: "assets/img/works/w1.jpg"` 改成你的文件名。

奖状要在页面上显示，还得在 `content.js` 最下面的 `awardImages` 里登记一行：

```js
const awardImages = [
  { src: "assets/img/awards/a1.jpg", caption: "包装类银奖证书" },
  { src: "assets/img/awards/a2.jpg", caption: "入选证书" },
];
```

点奖状可以放大。

## 三、增删作品 / 奖项

复制一整段 `{ ... }` 就是一个新的作品，删掉整段就是删除。分类名（`category`）如果写了新的，记得同步加到上面的 `categories` 数组里，否则筛选按钮里不会出现。

## 四、放到网上（可选）

现在这版是本地的，只能在自己的电脑上打开。要让别人也能打开（比如把链接写进简历），最简单的三种：

1. **GitHub Pages**：建仓库 → 上传整个文件夹 → Settings → Pages 开启，免费；
2. **Netlify / Vercel**：把文件夹拖进网页即可上线，免费额度够用；
3. **国内的静态托管**（如阿里云 OSS、腾讯云 COS）：需要备案，稍麻烦。

> 提示：网站里没有放任何追踪代码、外部请求，图片也都在本地，所以加载很快，也不会因为外网断了而打不开。

## 五、常见问题

**Q：打开是一片空白？**
A：多半是 `content.js` 里少了个引号或逗号。按 F12 打开控制台，红色报错会指出第几行。

**Q：图片不显示？**
A：检查文件名后缀是 `.jpg` 还是 `.png`，以及路径大小写是否一致（Windows 不区分，但上传到网上后服务器区分）。

**Q：想换成竖版作品图？**
A：在 `style.css` 里搜 `.card__media img`，把 `aspect-ratio:4/3` 改成 `3/4`。

```js

```

保存刷新，首屏和右上角就会自动出现「简历」按钮。

## 九、视频是怎么处理的（想换片时看这里）

网站里的视频在 `assets/videos/`，封面在 `assets/img/works/`（同名 .jpg）。
换片流程（在命令行里跑）：

```bat
ffmpeg -i 原片.mp4 -vf "scale=-2:720" -c:v libx264 -preset veryfast -crf 27 -c:a aac -b:a 96k 新片名.mp4
```

加了水印的版本是这样压的（水印图是 `assets/img/watermark.png`）：

```bat
ffmpeg -i 新片名.mp4 -i watermark.png -filter_complex "[1:v]scale=210:-1[wm];[0:v][wm]overlay=W-w-32:H-h-26" -c:v libx264 -crf 26 -c:a copy 输出.mp4
```

封面抽帧：

```bat
ffmpeg -ss 3 -i 输出.mp4 -frames:v 1 -q:v 4 封面.jpg
```

然后在 `content.js` 的 `works` 里加一条，`image` 指封面、`video` 指视频即可。
